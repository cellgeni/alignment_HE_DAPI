## local_registration
Folder with the python code which uses microaligner optical flow registration tool as fine local alignment for pre-registered images. at the moment is not working great, can align some cells to each other, but not all

## Align2sections 
Python code - example of semi-manual alignment of one pair of H&E to Xenium images with further applying transformation matrix for the annotated regions (defined for H&E iamge) and reassign them to cells defined by Xenium segmentation (in DAPI image)
